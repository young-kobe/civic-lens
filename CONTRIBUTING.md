# Contributing to Civic Lens

Civic Lens is open source under the [AGPL-3.0](LICENSE) so that its
methodology is fully inspectable, but it is a **single-maintainer project
that does not accept code contributions**.

- **Issues, bug reports, and methodology critique are welcome** — if you
  see a labeling problem, a sampling-bias concern, or a bug, please file
  an issue.
- **Pull requests will be closed without review.** Keeping a single
  copyright holder preserves the project's ability to offer commercial
  licensing alongside the AGPL in the future. Nothing personal.

You are of course free to fork and modify under the terms of the AGPL-3.0.
