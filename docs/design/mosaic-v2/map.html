    Where the data comes from
    Votes
    House Clerk roll call 308 file. It lists every member with party, state and cast.
    Seats
    The Clerk file gives no district number. Civic Lens matched each member to a district with the congress-legislators roster. All 433 members matched. Two seats had no member in the Clerk file, so the map shows them as vacant: Florida 20 and Texas 23.
    Shapes
    Census Bureau 2024 cartographic boundary file for the 119th Congress, at 1:20,000,000 scale, simplified more for the web. Alaska and Hawaii sit in boxes. Use the shapes to see the pattern, not to find an address.
    Delegates
    Six non-voting delegates (DC, Puerto Rico, Guam, U.S. Virgin Islands, American Samoa, Northern Mariana Islands) are circles. They can vote in committee. They cannot vote on passage.
