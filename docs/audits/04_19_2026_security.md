# Civic Lens Security Audit — 2026-04-19

Scope: readiness for public-internet deployment at `civic-lens.info`. Companion to `04_19_2026.md` (general code hygiene); this doc is security-specific. Severity legend: **CRITICAL** = pre-deploy blocker, must fix. **HIGH** = fix before any public traffic. **MEDIUM** = fix in first iteration post-deploy. **LOW/INFO** = hygiene / defense-in-depth.

## 1. Secrets and Credential Exposure

- **[CRITICAL] Live Gemini API key present in `.env` on disk.** `.env:5` contains a working Google AI credential. `.env` is correctly gitignored (`.gitignore:4`) and not in git history (verified via `git log -- .env` and `git log -S "AIzaSy"`). The exposure risk is the developer laptop itself — backups, screen-sharing, accidental paste. **Fix:** rotate the key in Google AI Studio before cutover; store the new value in a real secrets mechanism (systemd `EnvironmentFile` with 0600 perms, or Cloudflare secrets); set a billing cap on the Google Cloud project.
- **[HIGH] `run.ps1` env loader does not strip surrounding quotes.** `run.ps1:43-52` splits on `=` and trims whitespace but leaves `"..."` in the value. Any secret written with quoted syntax is corrupted silently. Fix: strip matched leading/trailing `'` or `"` pairs.
- **[INFO] No secrets in git history.** Searched `AIzaSy`, `BEARER`, known key prefixes across `git log -p --all`. `.env.example` and `data/seeds.yaml` carry only placeholders / comments.
- **[INFO] No `VITE_*` env vars at all.** `grep -r VITE_ ui/` returns zero. Nothing is baked into the client bundle via Vite's compile-time env. No LLM prompts, model IDs, schemas, or API keys reach the browser — the UI is pure fetch to `/api/*`.
- **[INFO] `ui/dist/` contains no sourcemaps.** `vite.config.ts` leaves `build.sourcemap` at its default (false). Build output is minified. Clean.

## 2. Admin / Auth Surface

There is **zero auth** in the codebase. `grep -E "Cookie|session|X-API-Key|X-Admin|Authorization|Depends\(|authenticate"` across `analysis/src/api/` returns no matches. Every endpoint is anonymous.

| Endpoint | Method | File:Line | Mutates? | Blast radius if abused |
|---|---|---|---|---|
| `/health` | GET | `server.py:65` | No | Info leak: `llm_enabled` flag |
| `/api/cache-status` | GET | `server.py:75` | No | Info leak: absolute `cache_dir` path |
| `/api/run/etl` | POST | `server.py:92` | **Yes, sync** | Fires ETL; blocks request thread |
| `/api/run/analysis` | POST | `server.py:99` | **Yes, background** | Queues full LLM loop over all unprocessed docs. N calls -> N queued runs. Unbounded Gemini / Ollama spend |
| `/api/run/full-pipeline` | POST | `server.py:106` | **Yes, background** | ETL + bot + text + citations + claims + narratives + snapshots. Highest-cost endpoint |
| `/api/sentiment` | GET | `server.py:166` | No | Read-only, cached |
| `/api/profiles` | GET | `server.py:176` | No | Read-only (orphan endpoint per general audit) |
| `/api/bot-activity` | GET | `server.py:191` | No | Read-only, cached |
| `/api/narratives` | GET | `server.py:207` | No for `limit<=100`; **live compute** otherwise |
| `/api/review/queue` | GET | `server.py:246` | No but leaks 1200-char raw text |
| `/api/review/submit` | POST | `server.py:264` | **Yes, DB write** | Writes `ai_output_evals`; `reviewer_id` user-supplied; `is_golden=true` accepted. Corrupts golden set |
| `/api/review/stats` | GET | `server.py:281` | No | Read-only |
| `/api/propaganda` | GET | `server.py:287` | No | Read-only, cached |
| `/api/geo-sentiment` | GET | `server.py:302` | No but **live compute** — no cache path |

- **[CRITICAL] `/api/run/*` is publicly callable with no auth, no rate limit, no CSRF.** Any internet user can fire `curl -X POST https://civic-lens.info/api/run/full-pipeline` in a loop and (a) exhaust the Gemini billing credit, (b) overwhelm Ollama, (c) fill the frontier with `INFLIGHT` rows. **Fix:** shared-secret `X-Admin-Token` header compared with `secrets.compare_digest`, plus Cloudflare Access in front of origin.
- **[CRITICAL] `/api/review/submit` lets any anonymous client write `is_golden=true`.** `server.py:264-278`. Eval-queue integrity — the foundation of the >95% accuracy claim — is trivially destroyed. **Fix:** same shared-secret gate; reject `is_golden=true` unless reviewer_id is on an allowlist.

**Recommended auth posture:**
- Cloudflare Access (Zero Trust, free up to 50 users) in front of `/api/run/*`, `/api/review/*`, `/api/cache-status`. Google-SSO to your email before origin.
- At origin, require `Authorization: Bearer $CIVIC_ADMIN_TOKEN` on mutate endpoints as defense-in-depth.
- Leave the GET read-path (`/api/sentiment`, `/api/narratives`, etc.) public — that's the product.

## 3. CORS and Cross-Origin

- **[CRITICAL] `allow_origins=["*"]` with `allow_credentials=True`.** `server.py:37-43`. Combination is spec-invalid (browsers drop credentials) and permits any origin to call the API. Combined with §2 unauth'd mutate endpoints, any page the admin browses can fire `/api/run/full-pipeline` on their behalf.

**Fix (path-based same-origin — recommended):** route `civic-lens.info/api/*` to the backend through Caddy. Same-origin means CORS middleware can be deleted entirely.

**Fix (if keeping cross-origin):**
```python
allow_origins=[
    "https://civic-lens.info",
    "https://www.civic-lens.info",
    # dev-only; gate behind settings.environment != "production"
    "http://localhost:5173",
],
allow_credentials=False,
allow_methods=["GET", "POST"],
allow_headers=["Content-Type", "X-Admin-Token"],
```

## 4. Rate Limiting and DoS

No rate limiting exists. `slowapi` is not in `analysis/requirements.txt`.

Endpoint cost tiers:
- **Expensive, mutate** — `/api/run/*` (unbounded LLM spend)
- **Expensive, read** — `/api/geo-sentiment` (always live compute); `/api/narratives` when `limit>100` (skips cache, `server.py:226`)
- **Cheap, read** — `/api/sentiment`, `/api/bot-activity`, `/api/propaganda`, `/api/profiles`, and `/api/narratives` with `limit<=100`

**[HIGH] Recommended per-class limits** (via `slowapi`, mounted on `app.state.limiter`):
- `/api/run/*`: 1/hour per IP, 3/hour global. Admin-only after §2 is done.
- `/api/review/submit`: 30/hour per IP.
- `/api/geo-sentiment`, `/api/narratives` (live path): 10/min per IP.
- Cached GETs: 120/min per IP default.

Mirror the `/api/run/*` limit at Cloudflare (Rate Limiting Rule, 10/hour) — defense-in-depth if the origin limiter bug-drops.

**[MEDIUM] No response-size cap on `/api/narratives`.** `server.py:207-227`. A request for `?limit=100000` triggers a live aggregation of 100k rows. **Fix:** `limit: int = Query(20, ge=1, le=100)`.

## 5. Input Validation / Injection

- **SQL injection — none found.** All f-string uses in SQL are for `?`-placeholder counts, not data; values bind through parameters. Checked: `bot.py:134,173`, Go `frontier.go:35-46,91-144`, `review.py:48-66`. Safe.
- **[HIGH] Query params unvalidated** — confirmed from general audit. `server.py:167` `window: str = "24h"` flows into `cache._get_path(f"sentiment_{window}")` (`cache.py:51-55`). `cache.py` sanitizes `/` and `\` but **not `..` or URL-encoded separators**. Today the attack surface is the cache dir only, but the sink exists. **Fix:** `Literal["24h","7d","30d","90d"]` on every endpoint; `Literal[...]` for `task`, `source_type` on `/api/review/queue`.
- **[MEDIUM] Path traversal in `SnapshotCache._get_path`.** `common/cache.py:51-55` does not reject `..`, nulls, or URL-encoded separators. **Fix:** reject these; also `resolve()` and assert the final path stays under `cache_dir.resolve()`.
- **[INFO] XSS in React UI — none found.** Zero matches for `dangerouslySetInnerHTML`, `innerHTML`, `document.write`. All API strings go through JSX text nodes (auto-escaped).
- **[INFO] SSRF in Go crawler — mitigated by frontier model.** URLs only enter via (a) seeds.yaml, (b) same-domain outlinks (`runner/crawl.go:161-165`), (c) `ClaimItems` which only returns pre-admitted `QUEUED` rows. No public "crawl this URL" endpoint. **Defense-in-depth:** before `Fetch()` in `httpclient/client.go:88`, reject RFC1918 / link-local / loopback hosts to guard against hostile RSS feed responses.
- **[INFO] Command injection in `run.ps1` — safe.** All `& $exe arg1 arg2` calls pass arguments as arrays (no `Invoke-Expression`). User-controlled input is constrained by PowerShell `ValidateSet`. Not network-reachable.

## 6. Data Exposure via API

- **[HIGH] `/api/review/queue` returns raw scraped content.** `review.py:81-97` returns `text_preview` up to 1200 chars of the original article/Reddit/X body, plus `ident` (tweet ID, Reddit post ID, article URL), `title`, `domain`. Concerns:
  - X/Twitter ToS: developer agreement requires honoring deletions/suspensions when redistributing tweet content.
  - Reddit content is CC BY-NC — re-display without attribution is a gray area.
  - Until gated, any scraper can harvest the sample set.
  **Fix:** admin auth (§2); add rate limiting; consider `?redact=true` that hashes idents.
- **[INFO] Cache JSON is safe.** Spot-checked `bot_activity.json`, `profiles.json` — all aggregate metrics + outlet names (public). No PII.
- **[INFO] `/api/cache-status` leaks the absolute `cache_dir` path.** Minor info leak. Return filenames only.
- **[INFO] No `StaticFiles` mount of `data/`.** `data/civic_lens.db`, `data/raw/**`, backups are NOT HTTP-reachable. Good.

## 7. Security Headers and Transport

- **[HIGH] FastAPI sends no security headers.** Default is `content-type, content-length, date, server: uvicorn`. Missing at origin:
  - `Content-Security-Policy` — UI loads fonts from `fonts.googleapis.com` / `fonts.gstatic.com` (`ui/index.html:9-13`); CSP needs `font-src` + `style-src` for those.
  - `X-Content-Type-Options: nosniff`
  - `X-Frame-Options: DENY` (or `frame-ancestors 'none'` via CSP)
  - `Referrer-Policy: strict-origin-when-cross-origin`
  - `Permissions-Policy` — lock down camera/mic/geolocation
  - `Strict-Transport-Security` — Cloudflare sets this at the edge; OK to skip at origin.
  **Fix:** one `@app.middleware("http")` that attaches these on every response.
- **[INFO] `api_host: "0.0.0.0"`** (`settings.py:17`) binds all interfaces. Fine if the origin firewall only accepts Cloudflare IPs; otherwise bind `127.0.0.1` and front with Caddy.
- **[INFO] `server: uvicorn` header is advertised.** Minor fingerprinting; nice-to-have to strip.

## 8. Dependency Posture

- **[MEDIUM] Python pins are soft `>=` in several places** (`analysis/requirements.txt:6-10`). Concrete version risks:
  - `fastapi==0.109.0` — from Jan 2024; CVEs fixed in 0.111+. Bump to 0.115.x.
  - `uvicorn==0.27.0` — DoS fix since; bump to latest.
  - `pydantic==2.5.3` — bump to 2.10+.
  - `requests==2.31.0` — **CVE-2024-35195 (session verify bypass)**. Bump to >=2.32.2. **HIGH.**
  - `google-generativeai>=0.8.3` is fine; `PyYAML>=6.0.1` is fine; `trafilatura`, `beautifulsoup4` current.
  **Fix:** generate a pinned `requirements.lock` via `pip-compile`; commit it; run `pip-audit` in CI.
- **[LOW] Go deps current.** `golang.org/x/net v0.49.0`, `modernc.org/sqlite v1.44.0` (pure Go — avoids CGo memory-safety surface), `cobra v1.8.0`. Clean.
- **[LOW] UI deps caret-pinned.** `react@^18.2.0`, `vite@^5.0.0`. `react-simple-maps@^3.0.0` is lightly maintained (last release 2022) — acceptable for now.

## 9. Build Output and Deploy Artifacts

- **[INFO] Vite build is clean.** Default `sourcemap: false`. Minified bundle. No baked-in secrets.
- **[LOW] No `<meta http-equiv="Content-Security-Policy">` in `ui/index.html`.** Either add one or rely entirely on the origin header from §7.

## 10. Database Exposure

- **[INFO] SQLite file is not HTTP-reachable.** `data/civic_lens.db` is filesystem-only; no `StaticFiles` mount. `.gitignore:13-16` ignores `*.db`, `*.db-journal`, `*.db-wal`. Clean.
- **[LOW] `db_path` is relative to cwd.** If uvicorn starts from a different working directory in production, a fresh empty DB will be created instead of the populated one. **Fix:** resolve absolute in `settings.py`, or set `CIVIC_DB_PATH` to an absolute path in the production env file.
- **[INFO] Do not ship the dev `data/civic_lens.db` to production.** Start the prod DB fresh and let the scheduled pipeline populate.

## Cross-cutting

- Ingestion layer (`ingest/`) is a CLI, not an HTTP service. It is not reachable inbound. Its only security-relevant surface is outbound SSRF (covered §5) and env-var handling (safe).
- Review queue is the weakest link in eval integrity. Pair §2 auth with a "only allowlisted reviewer_ids can set `is_golden=true`" check.
- Background tasks use `BackgroundTasks` (not a real queue). If uvicorn restarts mid-task, the job vanishes with no retry. Not a security bug, but compounds the DoS surface — N concurrent `/api/run/full-pipeline` calls all run in the uvicorn process with no cap.

## Production Deploy Blockers

Priority order. These MUST be fixed before `civic-lens.info` goes live.

1. **[CRITICAL] Rotate Gemini key** in Google AI Studio. Set billing cap. Move to secrets-manager / systemd `EnvironmentFile`.
2. **[CRITICAL] Gate `/api/run/*` and `/api/review/submit`** with shared-secret (`X-Admin-Token`) + Cloudflare Access.
3. **[CRITICAL] Lock CORS.** Either go same-origin path-based (delete middleware) or explicit allowlist. Set `allow_credentials=False`.
4. **[HIGH] Add `slowapi` rate limits** per §4. Mirror `/api/run/*` at Cloudflare.
5. **[HIGH] Validate every query param with Pydantic** — `Literal[...]` for enums, `Query(20, ge=1, le=100)` for `limit`.
6. **[HIGH] Harden `SnapshotCache._get_path`** — reject `..`, nulls, assert resolved path stays under `cache_dir`.
7. **[HIGH] Gate or redact `/api/review/queue`** — currently leaks 1200-char raw text for every scraped doc.
8. **[HIGH] Upgrade `requests==2.31.0`** (CVE-2024-35195). Bump `fastapi`, `uvicorn`, `pydantic` to current majors. Commit a lockfile.
9. **[HIGH] Security-headers middleware** (CSP, X-CTO, Referrer-Policy, Permissions-Policy, X-Frame-Options).
10. **[MEDIUM] Bind `api_host=127.0.0.1`** in prod; front with Caddy; firewall origin to Cloudflare IP ranges.
11. **[MEDIUM] Redact `cache_dir` absolute path** from `/api/cache-status`.
12. **[MEDIUM] Real `/health`** — touch cache metadata, open SQLite connection, return 503 on failure.

Everything else — `_get_cached_or_fallback` refactor, the Ollama 0-100 confidence bug, the propaganda aggregator de-dup — is not security-critical and can ship post-launch.
