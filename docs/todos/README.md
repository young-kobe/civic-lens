# Todos — future work

Checklists for work that is planned but not yet started. One file per initiative.

**Rules:**
- Each file is a checklist (`- [ ] item`). Keep items small enough that the next person can pick up one box without a preamble call.
- When an item ships, check the box and, in the same commit, add a dated entry under the appropriate layer in `../audit-trail/<layer>/`.
- When every box in a todo ships, delete the file — the audit trail is the permanent record.
- No half-finished plans, no speculative "someday" entries. If it's not concrete enough to tick off a box, it doesn't belong here.

Index is implicit — `ls docs/todos/` is the index.
