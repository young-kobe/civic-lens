TASK: the action draft step drafts an AI summary from the official bill text, behind a setting that is off by default. This one PR covers PRs 1, 2 and 3 of survey/explain-legislation.md on branch origin/survey-explain-legislation (read it first with git show origin/survey-explain-legislation:survey/explain-legislation.md). They ship together because a text read or citation table with no production caller is not allowed.

Owner decisions (accepted, do not reopen):
- One writer chooses the source, in this order: the CRS summary, then the bill text, then the code-written text (ActionCodeText). No second drafting path. The text branch goes between the summary test and the code write in ActionDraftStep.DraftOrWriteAsync.
- Read the gate text through text_package_id from bill_text_versions and its extraction (see docs/architecture/bills.md, ActionBillReader for the summary read precedent). A bill with a CRS summary never gets text.
- The model is the existing action draft model constant. It writes 2 or 3 summary sentences and a "why it matters" part. Why it matters covers only what the text states: who it affects and what it changes. No judgment. Every sentence of both parts must quote the text exactly; code checks each quote as a citation span inside the stored extraction, like ActionCitations and ActionDraftRevision.ValidateAgainst do today. A draft with a sentence that has no valid quote fails its checks.
- The prompt sends only the first 60,000 characters of the text (the chars_read cap). Store characters read and characters total where the publish PR can read them later (bill_text_versions already holds chars_total and chars_read; reuse them, do not copy them).
- D1: a child table action_revision_text_citations keyed on (record_id, revision_number, position), with a part column (summary or why it matters) and the span columns. Add text_package_id and why_it_matters columns to action_revisions. A revision cites the CRS summary or the text, never both: enforce it in Core (ActionDraftRevision.ValidateShape) and with a check constraint. Precedent: action_revision_sponsorship_citations in migration 20261103165049_ActionRevisionColumns.
- D2: a separate prompt version action-text-prompt-v1 and schema version action-text-schema-v1, added to ActionDraftTask.CurrentPromptVersions, beside the existing IssuePromptVersion precedent. Do not bump action-draft-prompt-v5.
- D3: the text branch is off unless the environment variable CIVIC_LENS_ACTION_DRAFTING_BILL_TEXT is 1. Read it in ActionDraftConfiguration beside the other CIVIC_LENS_ACTION_DRAFTING_ variables; any value other than unset or 1 is an error. Off: the step behaves exactly as today. On: the text draft runs and code approves after its checks. Document in docs/operations.md and docs/architecture/actions.md that the setting stays off until the owner reads the measured sample and the publish PR merges.
- No public page, contract (Publication.Contracts) or public_api change in this PR. The publish PR follows later.
